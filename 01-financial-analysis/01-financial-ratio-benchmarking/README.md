# Financial Ratio Benchmarking & Performance Monitoring

This project benchmarks selected companies using financial ratios related to liquidity, profitability, solvency, and operating performance.

## Project Files

- Financial ratio benchmarking report PDF
- Excel analysis workbook

## Objective

The objective of this project was to analyse company financial health using a structured ratio-based benchmarking framework.

## Analysis Areas

- Liquidity analysis
- Profitability analysis
- Solvency analysis
- Operating margin comparison
- Debt-to-equity comparison
- Interest coverage analysis
- Financial health scoring

## Tools Used

- Microsoft Excel
- Financial statements / company filings
- Ratio analysis framework

## Skills Demonstrated

- Financial statement analysis
- Financial ratio benchmarking
- Excel modelling
- Performance monitoring
- Financial health assessment
- Business interpretation of financial KPIs
